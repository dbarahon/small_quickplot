# Collection QuickPlot

GEOS HISTORY.rc-driven plotting on Discover. Uses the installed GEOS_Util
GrADS runtime, field aliases, GEOS QuickPlot plotting resources and
observational verification recipes. One Slurm job processes one collection.

## Submit jobs

Edit `gcm_collections.j` to set `GEOSUTIL`, experiment directory,
season, dates, requested pressure levels and workers. From this directory:

```csh
sbatch gcm_collections.j geosgcm_prog
tcsh submit_collections.csh geosgcm_prog geosgcm_moist geosgcm_surf geosgcm_aercloud
```

Without arguments, `submit_collections.csh` submits those four collections.
Each job has a separate output directory, for example:

```text
experiment/plot/collections_JJA_geosgcm_prog_JOBID/
  plots/              # All finished PNG/GIF files in one flat directory
  logs/               # One log per task
  plan.json           # Tasks, skipped recipes, selected verification resources
  summary.json        # Results and actual output paths
```

## Plot selection

The default run creates 3D horizontal maps at **850, 500, 250 hPa**,
3D latitude-pressure zonal sections, and maps for 2D fields. **2D latitude
line plots are not generated by default.**

Options for `collection_quickplot.py`:

- `--levels 850,500,250,100`: select other pressure levels.
- `--lines`: additionally make 2D zonal-mean latitude profiles.
- `--no-zonal`: omit 3D zonal sections.
- `--exclude-2d`: omit 2D maps (and 2D lines).
- `--no-native`: disable native GEOS verification recipes,
  retaining model-only derived maps and the usual `hcmp2` tasks.
- `--native-limit 5`: run only the first five matching native recipes for a
  short compatibility test; omit it to include all matching recipes.
- `--no-verification`: disable both native recipes and `hcmp2`
  verification plots.
- `--compare /path/to/experiment`: add an explicit experiment comparison
  (repeatable).
- `--keep-workdirs`: preserve temporary working directories.

Without `--execute`, the program writes a plan without running GrADS.
The output directory must not yet exist. When running interactively, supply
`--source`, `--geosutil`, `--collections`, `--season`, `--begdate`,
`--enddate`, and `--output`.

## Scientific diagnostics and plotting style

Model-only maps, zonal sections and derived maps now use a single
`geos_model_style.gs` rendering component. It follows the GEOS
`hcmp/hplt` and `zcmp/zplt` single-panel presentation conventions:
portrait viewport, plotting area, axes, borders, `rgbset` color definitions,
GEOS resource-controlled contours/colors, colorbar and annotated titles.
Model-only maps use `grads_util/plot.rc`; 3D zonal sections first use
the corresponding `_Z_CLEVS` and `_Z_CCOLS` resources. Derived maps
use `plots/NAME/plot.rc`. `model_map.gs` still handles unit conversion
and time averaging, and `model_zonal.gs` handles longitude averaging.
The same shared renderer is called from `model_derived.gs`.

This reuses the graphical conventions and resource lookup logic, not the
native three-panel model/verification/difference page: that layout requires
comparison data. Exact pixel-equivalence is **not** claimed, because
`hplt` also contains special dynamic contour rules for individual
meteorological fields. Native verification/comparison figures still use
their installed GEOS routines unchanged.

The model-only derived maps reproduce the original QuickPlot
`modform.gs` formulas:

| Product | Expression (GEOS exports) |
| --- | --- |
| `precip` | `86400 * (CN_PRCP + LS_PRCP + AN_PRCP)` (mm/day) |
| `olrcf` | `OLC - OLR` |
| `osrcf` | `RSC - RSR` |
| `toacf` | `OLC - OLR + OSRCLR - OSR` |

These plots use the corresponding GEOS `plots/NAME/plot.rc` resources.
A four-panel model-only `TOA_radz` plot is also available when its required
radiation exports exist.

## Verification and comparison products

The tool enumerates the installed GEOS `portrait.script -v -list`
recipes and dispatches matching native `genplot`, precipitation and
TOA radiation comparison recipes for each selected collection. The
installed GEOS `VERIFICATION_RCS` directory is used as the allowed
observational resource catalog. Depending on the site's installed
resources and enabled fields, this includes CERES EBAF, GPCP, ISCCP,
MAC-LWP, SRB and ERA5; MERRA-2 and ERA5 operational comparison
experiments are also included when present.

Native products retain their original descriptive filenames, preceded
by a collection/recipe prefix. Each task runs in an isolated directory;
completed images are kept even if later diagnostics fail.

**Compatibility note:** Original GEOS `genplot.gs` uses `sdfwrite`,
which fails with some monthly time coordinates under OpenGrADS 2.0.1.
The utility prepares a local, task-specific copy that avoids rewriting
the model grid's time axis; the installed GEOS code is unchanged.
This compatibility path is experimental and **must be validated against
original QuickPlot figures before scientific use**, particularly if the
model grid and comparison grid differ. Native recipe discovery and
availability depend on the installed GEOS_Util version.

For failures, inspect the corresponding log named in `summary.json`.
An all-undefined contour is a genuine data/level problem; the normal
`ga-> [EOF]` at GrADS shutdown is not an error.

## GrADS script-path troubleshooting

The installed `plots/configure` sets `GASCRP` to `GEOSUTIL/plots/grads_util`. Do not replace it with a colon-separated search path: OpenGrADS 2.0.1 may then fail to locate `getvar`, `getenv`, `getresource`, `rgbset` and `setdates`, causing every task to fail before opening a dataset. The launchers preserve this setting. The local `geos_model_style.gs` is invoked using an absolute path via `COLLECTION_QUICKPLOT_DIR`.

## Zonal figure presentation

Model-only zonal sections now use a taller latitude-pressure panel, a
horizontal colorbar and fine contour overlays, following the provided GEOS
QuickPlot examples. CCN-prefixed number-concentration exports are displayed
with a 10^-10 multiplier (title indicates x10^10) to avoid unhelpful 10^8
colorbar values. This changes only displayed units, not the underlying data.
Other variables continue to use GEOS `plot.rc` levels if available.
The supplied QuickPlot CCN image was from a different experiment, so it is
used as a style reference only, not a numerical validation.
